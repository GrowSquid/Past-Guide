# Past Dwellers Guide

An optional and supplementary guide for Past Dwellers.
An interactive website with minimal spoilers of the story

## how to use it
Run the html code, or open the website directly:

https://past-aquamarine-eap7srmm.edgeone.dev/

## how it works
The guide is stored as a list of screens with some text and buttons

When a button is executed, the page changes to the screen that is attached to the button
## building
```
npm install
node build.mjs
```
